# Excalidraw

## Introduction

Taking into account today's class (2024-09-03) [PROGRAMMING FUNDAMENTALS: Integrative Activity I](https://app.egg.live/content/step/1vCUDVdXVVcbVwu4iTUA9k), which recommends the use of graphical tools for communication and planning the algorithms we are going to create, I have brought you some resources to learn how to manage [**Excalidraw**](https://excalidraw.com/).

The first (though not always) source for learning how to use any tool is the official documentation on its website—usually the *Get Started* section, but in this case, it is called [*How to start*](https://plus.excalidraw.com/how-to-start/).
